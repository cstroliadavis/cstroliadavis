### Featured Open-Source Projects & Tooling

- [**`vscode-tailor`**](https://github.com/cstroliadavis/vscode-tailor) — Modular VS Code workbench extension featuring an interactive CSV Grid Editor, Rainbow CSV syntax highlighting, and toggleable productivity modules.
- [**`logging`**](https://github.com/cstroliadavis/logging) — Event-driven TypeScript/Bun logging library with TC39 Stage 3 decorators, `AsyncLocalStorage` context propagation, and Datadog JSONL formatting.
- [**`csv-lib`**](https://github.com/cstroliadavis/csv-lib) — Lightweight, zero-dependency RFC 4180 streaming CSV parser and serializer for Bun and modern JavaScript runtimes.

- [**`mcp-concept-mem`**](https://github.com/cstroliadavis/mcp-concept-mem) — Model Context Protocol (MCP) server architecture for hierarchical AI agent memory with dynamic typing and self-modifying rules.
- [**`s20`**](https://github.com/cstroliadavis/s20) — Spouse 2.0 (`s20`) CLI time-tracking and reporting toolkit built on Bun and TypeScript.
